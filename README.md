## À propos

Diplômé du **Common Core de l'École 42**, je conçois des logiciels bas niveau en C et
C++ : serveurs réseau, moteurs de rendu, infrastructures conteneurisées. Mon approche
repose sur une règle simple — **comprendre avant d'utiliser** : implémenter les
mécanismes depuis zéro avant de s'appuyer sur des abstractions.
